1. 📁 src/scraper.py (AMÉLIORÉ)
   • Méthode: BeautifulSoup + CSS selectors
   • Amélioration: 3 stratégies de fallback
   • Performance: 0.79s par page
   • Utilisation: python scrape_all_sources.py

2. 📁 src/scraper_lxml.py (NOUVEAU - RECOMMANDÉ ⚡)
   • Méthode: LXML + XPath
   • Performance: 0.25s par page (3.1x plus rapide)
   • Utilisation: python src/scraper_lxml.py
   • Gain: 68% d'accélération vs BeautifulSoup

3. 📁 src/scraper_requests_html.py (NOUVEAU)
   • Méthode: Requests-HTML (CSS + XPath)
   • Support: JavaScript rendering optionnel
   • Performance: 0.5-2s par page
   • Utilisation: python src/scraper_requests_html.py

4. 📁 src/scraper_playwright.py (NOUVEAU)
   • Méthode: Playwright (navigateur headless)
   • Support: JavaScript complet
   • Performance: 2-5s par page
   • Utilisation: python src/scraper_playwright.py
   • Installation: pip install playwright && playwright install

5. 📁 compare_scrapers.py (UTILITAIRE)
   • Benchmark des performances
   • Comparaison BeautifulSoup vs LXML
   • Résultats: LXML 3.1x plus rapide

6. 📁 GUIDE_SCRAPING.py (DOCUMENTATION)
   • Guide complet avec exemples
   • Matrice de décision
   • Cas d'usage pour chaque méthode

7. 📁 METHODES_SCRAPING.txt (RÉFÉRENCE)
   • Documentation détaillée
   • Avantages/inconvénients
   • Installation des packages

✅ UTILISER: LXML (src/scraper_lxml.py)

Raisons:
  • Vous scrapers des articles statiques (pas de JavaScript)
  • 3.1x PLUS RAPIDE que votre méthode actuelle
  • Léger en ressources (parfait pour serveur)
  • XPath très puissant pour la sélection d'éléments
  • Test réel: 0.79s (BeautifulSoup) → 0.25s (LXML)

Gains chiffrés:
  • 100 pages: 79s → 25s
  • 1000 pages: 13min → 4min
  • 10000 pages: 2h13 → 42min

Installation:
  pip install lxml

Utilisation rapide:
  python src/scraper_lxml.py
